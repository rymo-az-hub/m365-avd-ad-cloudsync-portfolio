# Runbooks

このディレクトリには、ラボ検証で作成した公開用Runbookを配置しています。

| Runbook | 用途 |
|---|---|
| [Runbook_AVD_StartConnect.md](Runbook_AVD_StartConnect.md) | AVD接続確認、Start VM on Connect前提確認 |
| [Runbook_AVD_StopDeallocate.md](Runbook_AVD_StopDeallocate.md) | AVD VM停止・deallocate運用 |
| [Runbook_AVD_Troubleshooting.md](Runbook_AVD_Troubleshooting.md) | AVD接続・セッション確認の切り分け |
| [Runbook_CloudSync_ConfigAndVerify.md](Runbook_CloudSync_ConfigAndVerify.md) | Cloud Sync構成・同期確認 |
| [Runbook_CloudSync_PHS_SignIn_Validation.md](Runbook_CloudSync_PHS_SignIn_Validation.md) | PHSサインイン検証 |
| [Runbook_Lab_Cost_Stop.md](Runbook_Lab_Cost_Stop.md) | ラボ全体の停止前確認とdeallocate |

## 注意

- このRunbookは個人ラボ向けです。
- 本番環境では、変更管理、影響評価、バックアップ、復旧手順、監査ログ保持、承認フローを追加してください。
- 実行結果には識別子やUPNが含まれる可能性があるため、公開リポジトリには貼り付けません。
