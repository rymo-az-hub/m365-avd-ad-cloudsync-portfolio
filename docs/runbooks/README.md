# Runbooks

This directory contains public, sanitized runbooks for the lab portfolio.

| Runbook | Purpose |
|---|---|
| Runbook_AVD_StartConnect.md | Validate AVD user access and Start VM on Connect behavior. |
| Runbook_AVD_StopDeallocate.md | Stop/deallocate AVD VM for lab cost control. |
| Runbook_AVD_Troubleshooting.md | Troubleshoot AVD access, session host, assignment, and VM state issues. |
| Runbook_CloudSync_ConfigAndVerify.md | Configure and verify Cloud Sync for AD DS to Entra ID. |
| Runbook_CloudSync_PHS_SignIn_Validation.md | Validate Password Hash Sync using AD password reset and cloud sign-in logs. |
| Runbook_Lab_Cost_Stop.md | Safely deallocate DC and AVD VMs after validation. |

All commands use placeholders or lab-safe names. Tenant-specific identifiers and raw evidence are excluded from the public repository.
